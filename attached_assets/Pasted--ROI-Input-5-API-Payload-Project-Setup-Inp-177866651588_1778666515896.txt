二、ROI 计算工具的【核心 Output 结构】

从决策角度，Output 可以分 4 层。

① 核心决策指标（Executive Outputs｜最重要）

ROI (%)
IRR (%)
NPV (USD)
Payback Period
Years
Months

✅ Gate 决策 / Investment Approval / VP Review

② 盈利能力指标（P&L Outputs）

Revenue

③ 现金流与资本回报（Cash Flow Outputs）

典型用途：
✅ 判断现金压力 & 回收节奏

④ 风险 / 管控型输出（Management Outputs）

CM% < Target 或 < 0 提示
Region Profitability 异常
Assumption Summary（FX / Freight / Duty / MDF）
典型用途：
✅风险提示
✅ Audit / Compliance support

三、一句话总结成「系统视角」

ROI 工具本质是：
「把 销量 × 价格 × 区域结构 + 成本 × 生命周期 + 前期投资
转换为 现金流，并输出 ROI / IRR / NPV / Payback 的决策引擎」
